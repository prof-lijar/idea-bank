# Idea Bank

## What is Idea Bank?

Idea Bank is the collection (bank) of **problems**, **solutions**, and **executions**. Some people upload their problems; some propose solutions to specific problem(s); some execute the solutions and share the results.

The best problem, the best solution, and the best execution is rewarded.

We can’t beat big tech in skills.

We can’t beat big tech in experiences.

We can’t beat big tech in infrastructures.

We can’t beat big tech in AI.

We can’t beat big tech in tokens.

We can’t generate tokens like them.

**We can beat them in ideas.**

**We can generate limitless ideas for FREE.**

**Our mission is to generate ONE IDEA that can beat.**

## Tech stack

- [Next.js](https://nextjs.org) (App Router), React, TypeScript  
- [Tailwind CSS](https://tailwindcss.com) v4  
- Package manager: [pnpm](https://pnpm.io)

## Development

Install dependencies (once):

```bash
pnpm install
```

Run the dev server:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000). The [About](http://localhost:3000/about) page expands on the project narrative.

Other scripts:

```bash
pnpm build   # production build
pnpm start   # run production server (after build)
pnpm lint    # ESLint
```

## Environment

Copy `.env.example` to `.env.local` when you add public URLs or API keys.
